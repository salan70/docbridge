---
name: docbridge
description: Maintain explicit documentation-to-code links.
---

Use `docbridge docs` and `docbridge docs list` for authoritative guidance.
Use `docbridge validate`, `docbridge links`, and `docbridge unlinked` to inspect explicit links.
`docbridge` must be on `PATH`. If it is not, look for how the project provides the CLI, such as through a wrapper script, before reporting DocBridge unavailable.
Read the relevant documentation and code before editing. Validation checks structural links; assess semantic consistency yourself.
