# Removal

Use `docbridge deinit --dry-run` to inspect the complete removal plan and detected DocBridge references. The resolved root is displayed before interactive confirmation; noninteractive input without confirmation fails without changes. The confirmed plan removes configuration and only recognizable standalone DocBridge annotation lines outside examples and ordinary comments. Ordinary Markdown, comments and code examples must be protected; malformed lookalikes are preserved for manual review. Annotation-looking lines inside an unclosed `<pre>`, `<script>`, `<style>` or `<textarea>` block are preserved, and the removal is reported as incomplete. Only owned, unchanged Skill files are removed; modified or unowned files are reported and preserved. Even edited configuration requires confirmation before removal.

Removal targets are preflighted before writes, with originals retained in a persistent private recovery directory until completion. Each file is rewritten via a temporary file and atomic replacement. An existing recovery directory is never overwritten or deleted. Interruption identifies changed and untouched files and the recovery path; removal or recovery failures are reported explicitly, not as complete success. Review remaining references in CI, hooks and scripts manually. The CLI is not automatically uninstalled; follow your standalone distribution or package manager's instructions.
